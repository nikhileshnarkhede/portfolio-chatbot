<research_project name="SymbOptAI" type="Symbolic Regression + DNN + Multi-Objective Optimization Framework" url="https://github.com/nikhileshnarkhede/SymbOptAI">
### SymbOptAI — Symbolic Regression + DNN + Multi-Objective Optimization Framework (Additive Manufacturing)
Nikhilesh built an end-to-end computational framework integrating Symbolic Regression Analysis (SRA), Deep Neural Networks, and NSGA-II multi-objective optimization to predict and optimize the mechanical properties of 3D-printed (FDM) materials.
- Used genetic-programming-based symbolic regression (gplearn) to discover interpretable closed-form equations linking four FDM printing parameters (layer thickness, printing speed, bed temperature, nozzle temperature) to six mechanical properties (tensile strength, elongation at break, toughness, fracture toughness, flexure modulus, flexure strength).
- Designed a Taguchi L9 Design of Experiments and augmented scarce experimental data with bootstrap resampling; ran an exhaustive 432-configuration symbolic-regression hyperparameter sweep on an HPC cluster (Unity, UMass).
- Extracted symbolic equation terms as engineered features to boost DNN accuracy, then applied NSGA-II for inverse design to find Pareto-optimal printing parameters across six simultaneous objectives.
- Achieved test R² of 0.897–0.992 with symbolic regression alone, improved to R² of 0.96–0.997 with the DNN surrogate, while preserving physical interpretability. Published as "Hybrid Machine Learning Workflow for Process-Property Optimization in Fused Filament Fabrication" in IJIDeM (Springer, 2026).
**DOI:** https://doi.org/10.1007/s12008-026-02637-y
**GitHub:** https://github.com/nikhileshnarkhede/SymbOptAI
**Skills:** Python, Symbolic Regression, gplearn, Genetic Programming, Deep Neural Networks, TensorFlow, NSGA-II, pymoo, Multi-Objective Optimization, Design of Experiments, Bootstrap Resampling, Feature Engineering, HPC / SLURM, Interpretable ML.

### Physics-Informed Neural Network (PINN) for IGBT Remaining Useful Life (NASA Aging Dataset)
Nikhilesh built a production-quality, config-driven PINN to estimate the Remaining Useful Lifetime (RUL) of IGBT power-electronic devices from the NASA Ageing dataset, reproducing and extending Lu et al. (Scientific Reports, 2023).
- Implemented an RNN/LSTM backbone with a physics-augmented loss that combines data fit with two physical constraints — a Monotonic Decreasing Constraint (RUL never increases over time) and a Boundary Condition Constraint (RUL stays within [0, 1]).
- Used a leak-free leave-one-device-out evaluation protocol so the held-out device never influences training or standardization, producing honest out-of-sample estimates.
- Engineered a fully modular, single-config-source codebase (data, physics, loss, model, training, evaluation) with MLflow experiment tracking, a per-run registry, and a seven-command CLI; the model architecture is declared entirely as configuration data.
- Achieved a test R² of 0.784. Built independently as a companion project alongside his Machine Learning Researcher role at Choir Corp (SENTRIX / UptimePowr platform), where he also reproduced a separate published PINN-LSTM benchmark (Kong et al., APEC 2025) for the same IGBT RUL problem.
**Skills:** Python, PyTorch, Physics-Informed Neural Networks (PINNs), LSTM, RNN, Time-Series Forecasting, Remaining Useful Life (RUL), MLflow, Reproducible ML, Production ML Engineering, Predictive Maintenance.
